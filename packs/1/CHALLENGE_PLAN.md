# K‑12 Challenge Set Plan

## Overview

The following plan defines the minimum structure for the challenge sets that will be used in the K‑12 children’s learning app.  Each grade level will have **at least 2 sets** and **no more than 5 sets**.  Every set contains **at least 7 challenges**.  The format below follows the requirements:

1. **Set 1 – Reinforcement** – higher difficulty, to confirm mastery of concepts from earlier grades.
2. **Set 2+ – New Concepts** – introduces new ideas and skills to expand learners’ abilities.
3. Odd‑numbered challenges (1, 3, 5, 7) may be **fun, silly or light‑hearted**.
4. Even‑numbered challenges (2, 4, 6) are **intriguing, clever or puzzling**.
